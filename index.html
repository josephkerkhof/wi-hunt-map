Install Field Hours

iPhone and iPad

In Safari, tap Share, then Add to Home Screen. Turn on Open as Web App if offered.

Android

In Chrome, open the menu and choose Install app or Add to Home screen.

Open the installed app while online and set your hunt location. Before heading out, try reopening it in airplane mode.
